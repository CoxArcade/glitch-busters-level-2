# Glitch Busters Level 2: Coordinate Chaos

This repository builds the Pygame game into a browser-ready GitHub Pages site using GitHub Actions and pygbag.

1. Upload the `game` folder, `.github` folder and `README.md` to the **root** of the `glitch-busters-level-2` GitHub repository. **Keep the folder structure.**
2. Open repository **Settings → Pages** and set **Source** to **GitHub Actions** (not Deploy from a branch).
3. Open **Actions → Build and publish Level 2** and wait for the green check. If no run starts, click **Run workflow**.
4. Visit https://coxarcade.github.io/glitch-busters-level-2/ .

Do not unlock Level 2 on the dashboard until it has been playtested.

This is an automatic build recipe, not a prebuilt browser bundle. Pygbag installation/build runs on GitHub. The build has not been executed in this environment.
